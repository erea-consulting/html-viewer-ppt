HTML Viewer (EREA)

Muestra un gráfico HTML interactivo dentro de una lámina. El HTML se guarda dentro del propio .pptx.

Descargar el manifest Ver el repositorio

Versión 1.1.0.0. La instalación toma dos minutos y se hace una sola vez por equipo.

Mac

  1. Abre Terminal y pega este comando:
mkdir -p ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef && curl -fsSL https://erea-consulting.github.io/html-viewer-ppt/html-viewer-erea-web.xml -o ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/html-viewer-erea-web.xml

  1. Cierra PowerPoint por completo (Cmd+Q) y vuelve a abrirlo.
  2. Ve a Insertar → Complementos → Mis complementos → HTML Viewer (EREA).

PowerPoint web

  1. Descarga el manifest con el botón de arriba.
  2. En PowerPoint web: Insertar → Complementos → Cargar mi complemento y sube el archivo.

Windows (escritorio)

  1. Guarda el manifest en una carpeta compartida de red.
  2. En PowerPoint: Archivo → Opciones → Centro de confianza → Configuración del Centro de confianza → Catálogos de complementos de confianza. Agrega la ruta de la carpeta y marca «Mostrar en el menú».
  3. Reinicia PowerPoint. El complemento aparece en Insertar → Complementos → Mis complementos → Carpeta compartida.

Uso

  1. Con la lámina activa, abre el complemento.
  2. Arrastra el archivo .html al panel, o usa Cargar HTML….
  3. Ajusta el zoom y guarda el deck: el gráfico queda dentro del .pptx.

Quien abra el deck sin el complemento ve un marcador vacío. Para enviar o exportar a PDF, usa el gráfico nativo de PowerPoint.

Privacidad

El visor es una página estática. El HTML que cargas se guarda en tu presentación y no se envía a ningún servidor.
